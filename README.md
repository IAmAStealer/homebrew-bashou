# Homebrew tap for Bashou

[Bashou](https://github.com/IAmAStealer/Bashou): a pixel-art pet in the corner of your terminal that grows as
you learn the shell, offline.

```bash
brew install iamastealer/bashou/bashou
bashou on
```

`bashou on` adds one line to your `~/.zshrc`; open a new terminal to meet your pet. `brew upgrade` updates it.

`Formula/bashou.rb` is written by Bashou's release workflow at each release: change `tools/package.py` in the
main repository, not this file.
